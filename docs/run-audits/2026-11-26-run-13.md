## Evidence and safety boundaries

- **FACT:** GitHub reported the current main SHA and the successful workflow runs listed above.
- **REPRODUCED RESULT:** the 20/35 and 154→262 calculations are arithmetic over source-published aggregates; they are not independent access to underlying country/activation records.
- **INFERENCE:** a missing local delivery/acknowledgement/action dataset prevents NOEMA from measuring Georgia's last-mile effectiveness at this time; it does not prove the local system is ineffective.
- **HYPOTHESIS:** separating endpoint receipt, human comprehension, feasible action and verified action will make future warning-to-action evaluation less prone to denominator conflation.
- **UNTESTED IDEA:** an independently administered signed checkpoint plus monotonic sequence could improve anti-rollback assurance; no such trust anchor is deployed.

Only public-source descriptions and synthetic fixtures are used. No operator telemetry, laboratory records, personal data, credentials, signing keys, encryption identities or private backup objects were added to the public repository.
