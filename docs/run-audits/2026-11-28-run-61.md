**FACT — surface-water frame**

- The 73 count is stored only as `surface_water.parameter_coverage_points` with scope `surface_water_only`.

**REPRODUCED_RESULT — arithmetic**
- 147 + 147 + 158 + 82 + 147 = 681.

**INFERENCE**
