## Evidence and limitations

- **FACT:** Python documents that `bool` is a subclass of `int`: https://docs.python.org/3/library/stdtypes.html#boolean-type
- **REPRODUCED RESULT:** hosted x86-64 synthetic CPU-thread summary described above. Three measured repetitions/configuration; no physical-device or ARM64 replication, RSS/native allocation or DRAM bandwidth.
- **REPRODUCED RESULT:** WRP 2025 pinned public Parquet aggregates remain unchanged after strict validation. Raw microdata is processed only on ephemeral CI runners; repository retains aggregate outputs only.
- **INFERENCE:** stricter type validation prevents malformed booleans, floats and strings from silently entering survey-code/weight calculations. It does not prove source authenticity or survey validity.
- **UNTESTED IDEA:** physical x86-64/ARM64 replication and independent hardware review remain outstanding.
- AquaSignal still needs an authorised NEA report copy, sample/station dictionary, reuse terms and NFA denominator.
- NOEMA-007 still needs authorised Georgian event-level warning and after-action aggregates.
- INFRA-001 still lacks an independent recovery owner/trust domain, production key custody and clean-host restore.
