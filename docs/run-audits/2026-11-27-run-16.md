### NOEMA RESEARCH — NOEMA-005 ARM64 worker scaling

A deterministic analysis was added in Draft PR #104 using the frozen source summary `data/noema-005/arm64-threaded-benchmark-summary-2026-11-26.json` (Git blob `682d747f08d6f723375bada2d20feea438556287`).

Derived from four runner/runtime cells (Ubuntu ARM64 and macOS ARM64; GIL-enabled and free-threaded), 192 configurations and 576 measured runs:
- Full Neumaier `(sum, correction)` state: 192/192 correctly rounded configurations.
- Scalar Neumaier partial merge: 168/192.
- Naive scalar: 0/192.
- Only two of four runner/runtime cells had any worker median speedup above 1.0; the best values were 1.006134x and 1.029768x, each based on three repetitions.
- Eight-worker peak `tracemalloc` allocation was 5.18x–7.69x the one-worker value. This is not process RSS or complete native memory.

The new analyzer, frozen JSON result, closed schema, regression tests and research addendum reproduce these derived values from the committed summary. This is not a new benchmark or raw-report reproduction. Three repetitions do not support confidence intervals; no general wall-time speedup is claimed.
