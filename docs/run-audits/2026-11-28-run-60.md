### Innovation

`noema_core/monitoring_frames.py` adds a fail-closed eligibility check. A record cannot support a water-only descriptive rate unless it is an actual drinking-water-only sample result with exact integer numerator/denominator, sample unit, sampling frame, indicator and denominator definitions, geography, period, standard and analytical method. This is only a metadata sufficiency gate, not a potability, legal-compliance or health-risk assessment.

NEA 2025 regional tables were transcribed into a public aggregate snapshot and checked against regional/column totals. The 124/74/50 groundwater and 238/2571/73 surface-water reporting frames remain distinct; unique-site overlap is unknown. The 50-point nitrate table is field-instrumental coverage only and contains no nitrate concentrations or final vulnerable-zone designation. Raw PDF bytes were not available, so no PDF SHA-256 is claimed.
