## AquaSignal — source discovery

### FACT

- MEPA's Geographic Information Portal lists catalogue record **NEA122**, *Groundwater monitoring*: point geometry, technical layer name `Groundwtaer_Monitoring_Stations_NEA`, classified public/free, catalogue date 2026-03-06.
- The same row lists SQL SDE server and local-computer storage but no portal-placement URL. The actual layer payload, schema, coordinates, freshness, export/API and reuse licence were not retrieved or verified.
- NEA's 2026-06-09 Tianeti field-practical notice describes automatic stations at monitored wells and procedures for portable field measurement, data registration, documentation and recording. It does not publish a raw telemetry feed.
- Article 32 of the Law of Georgia on Water Resources Management describes NEA's surface/groundwater monitoring data role and says quantitative/qualitative observations are provided to interested parties on request; drinking-water quality state control is assigned separately to the National Food Safety Agency.
- NEA's 2026-11-26 announcement links a 2021–2025 groundwater report and nitrate-risk field methodology archive. The RAR archive was not retrieved or inspected in this run.
- Government Resolution No.424 (2026-08-31, effective 2026-09-01) creates a prospective register for fresh drinking-water extraction wells deeper than 20 metres drilled after the rule takes effect. The legal text excludes pre-existing wells; NEA additionally states household wells are excluded. Well passports may contain personal owner data and coordinates, so none were copied.

### INFERENCE

The discovery state is no longer “no station registry identified”. The accurate classification is: **public/free station-layer catalogue metadata exists, but the actual spatial payload and access path remain unverified; sample-level analytical time series and reuse terms are still outstanding.** A station registry is not a laboratory sample feed. Environmental groundwater and potable-network compliance require separate adapters, owners and schemas.

### INNOVATION

PR #92 adds a closed JSON Schema and regression tests for source-access status, including explicit checks that catalogue metadata is not misrepresented as a downloadable sample dataset. The note and portfolio now distinguish:
1. station-registry metadata;
2. groundwater monitoring results;
3. potable-network compliance.

No raw sample rows, private operator telemetry, owner identity, exact well coordinates or credentials were added.
