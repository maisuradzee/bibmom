### NOEMA RESEARCH — NOEMA-005 numerical reduction

Five hosted runs on the same frozen synthetic input/protocol now show:

- Full Neumaier (sum, correction) state: 48/48 correctly rounded cases in each runtime.
- Scalar Neumaier partial merge: 42/48.
- Naive scalar reduction: 0/48.
- Hosted free-threaded median speedup against matching serial Neumaier varied from 0.7008× to 1.2589×; GIL-enabled ranged from 0.7576× to 0.7620×.
- Serial math.fsum remained a stronger speed baseline on these fixtures.

The fifth run's raw GIL-enabled and free-threaded JSON reports and artifact digests were archived in PR #99. The two runtime reports came from different AWS x86-64 host images, so cross-mode timing is additionally confounded. These hosted virtual-machine results do not establish physical-hardware or application-workload performance.
