# NOEMA-2026-011 — Groundwater quantitative-status readiness and Decree №447 Annex source audit

- **ID:** NOEMA-2026-011
- **კვლევითი ნაკადი:** AquaSignal / NOEMA-2026-006
- **თარიღი:** 2026-11-28
- **სტატუსი:** Preliminary
- **მტკიცებულების სტატუსი:** FACT (official HTML Articles 7(1)-(2)); SECONDARY_TRANSCRIPTION_ONLY (Annex 2); REPRODUCED RESULT (synthetic software tests)
- **დამოუკიდებელი იურიდიული რეცენზია:** არ ჩატარებულა

## კვლევითი კითხვა

როგორ უნდა აიცილოს AquaSignal-მა მიწისქვეშა წყლის რაოდენობრივი სტატუსის ნაადრევად შეფასება, თუ ოფიციალური groundwater-body designation ან პასუხისმგებელი უწყებების მიერ წყალაღების მონაცემებზე დაფუძნებული წყლის ბალანსი ჯერ არ არსებობს?

## FACT — ოფიციალური Matsne HTML

საქართველოს მთავრობის №447 დადგენილების ოფიციალური HTML ტექსტის მუხლი 7(1) ადგენს, რომ მიწისქვეშა წყლის ობიექტების განსაზღვრამდე წესის მოთხოვნები ვრცელდება ჰიდროგეოლოგიურ ერთეულებზე.

მუხლი 7(2) რაოდენობრივი სტატუსის შეფასებისთვის მიწისქვეშა წყლების შევსებასა და წყალაღებას შორის ბალანსის შეფასებას უკავშირებს იმ პირობას, რომ შესაბამისმა პასუხისმგებელმა უწყებებმა შეადგინონ წყალაღების მონაცემებზე დაფუძნებული წყლის ბალანსი.

ეს არის დოკუმენტური წინაპირობა და არა კონკრეტული წყალშემცველი ჰორიზონტის კარგი/ცუდი სტატუსის დასკვნა.

## SECONDARY_TRANSCRIPTION_ONLY — Annex 2

Matsne-ის ოფიციალური გვერდი ჩამოთვლის 46,049-ბაიტიან `447-დან.docx` დანართს. მისი ჩამოტვირთვა ამ ციკლში ვერ მოხერხდა: endpoint-მა დააბრუნა `application/msword`, ხოლო ფაილის ბაიტები და SHA-256 არ მიგვიღია.

Legali.ge-ის გვერდზე გამოქვეყნებული მეორადი ტექსტური ტრანსკრიფცია შეიცავს Annex 2-ის შემდეგ ჩანაწერებს:

- მიწისქვეშა წყლების ქიმიური შედგენილობა: საწყის სტატუსის შეფასებამდე სულ მცირე წელიწადში ორჯერ; შეფასების შემდეგ — სულ მცირე წელიწადში ერთხელ.
- რაოდენობრივი მახასიათებლები: საწყის შეფასებამდე თვეში ან კვარტალში ერთხელ, წყალპუნქტის ტიპის მიხედვით; შეფასების შემდეგ — რისკზე დაფუძნებით.
- რისკის ქვეშ მყოფ ობიექტებზე ოპერატიული ქიმიური მონიტორინგი — კვარტალურად ან რისკზე დაფუძნებით; რაოდენობრივი მონიტორინგი — ყოველთვიურად ან კვარტალურად, რისკზე დაფუძნებით.
- რაოდენობრივი მახასიათებლების უწყვეტი დაკვირვება, სადაც შესაძლებელია; სხვა შემთხვევაში ყოველთვიური გაზომვა; სტატუსისა და ტენდენციების წლიური მიმოხილვა.
- ნიტრატის სინჯის აღებისას საველე პარამეტრები და სტანდარტული ლაბორატორიული ანალიზი; ტუმბოიან ჭაბურღილებში low-flow მიდგომა, როდესაც დებიტის კონტროლი შესაძლებელია და ამით წყალშემცველი ჰორიზონტის დარღვევა მცირდება.

**ეს ჩანაწერები არ არის დადასტურებული პირველადი ფაქტები.** ისინი გამოიყენება მხოლოდ როგორც Annex-ის მოსაძიებელი პუნქტების სია, სანამ ოფიციალური DOCX არ იქნება მიღებული, ჰეშირებული და დამოუკიდებლად შედარებული. მათზე დაყრდნობით არ განისაზღვრება წარმოების სიხშირე ან შესაბამისობის წესი.

## INFERENCE — მონაცემთა მოდელის მოთხოვნები

1. მიწისქვეშა წყლის ობიექტის ოფიციალურ განსაზღვრამდე გამოიყენე `hydrogeological_unit_id`; `groundwater_body_id` არ უნდა მიენიჭოს ნაადრევად.
2. რაოდენობრივი სტატუსის შეფასების წინაპირობები არ ჩაითვალოს შესრულებულად, თუ არ არსებობს პასუხისმგებელი უწყების მიერ დადასტურებული და წყალაღების მონაცემებზე დაფუძნებული წყლის ბალანსის provenance.
3. სინჯის მატრიცა, წყალპუნქტის ტიპი, მონიტორინგის რეჟიმი და სინჯის აღების მეთოდი შეინახე ცალკე ველებად.
4. მონაცემის არქონა არ უნდა იქცეს არც ნულოვან წყალაღებად და არც კარგ რაოდენობრივ სტატუსად.

## HYPOTHESIS

Evidence-gated readiness მოდელი შეამცირებს შემთხვევებს, როდესაც მონაცემთა პლატფორმა წყლის რაოდენობრივ სტატუსს „შეფასებულად“ მონიშნავს აუცილებელი წყლის ბალანსის გარეშე. ეს ჰიპოთეზა რეალურ NEA მონაცემებზე ჯერ არ შემოწმებულა.

## ინოვაციური პროტოტიპი

შეიქმნა `noema_core/aquasignal_groundwater.py`. იგი:
- არჩევს ჰიდროგეოლოგიურ ერთეულსა და ოფიციალურად განსაზღვრულ groundwater body-ს;
- ითხოვს წყლის ბალანსის წყაროს, SHA-256-ს, პასუხისმგებელი უწყების დადასტურებას და წყალაღების მონაცემებზე დაფუძნების ატრიბუტს;
- არასრული მტკიცებულებისას აბრუნებს `BLOCKED_*` მდგომარეობას;
- სრული metadata-ისას აბრუნებს მხოლოდ `PREREQUISITES_MET_REQUIRES_AUTHORITY_ASSESSMENT`;
- არასდროს ანიჭებს `good` ან `poor` სტატუსს და ყოველთვის ითხოვს უფლებამოსილი უწყების შეფასებას.

პროტოტიპი ამოწმებს caller-supplied metadata-ს; იგი არ ამოწმებს დოკუმენტის ხელმოწერას, უწყების უფლებამოსილებას ან წყლის ბალანსის გამოთვლას.
